# 2 工具概述

文件系统配置验证工具（FAT\_Gen\_Verify）是FAT\_Gen工具的配对工具，验证FAT\_Gen工具生成的二进制FS可加载文件的结构和内容，确保二进制FS可加载文件中的数据在生成过程中未发生计算错误，没有被破坏、丢失或添加。

FAT\_Gen\_Verify工具的输入输出示意图如下图所示。

![](https://cdn-mineru.openxlab.org.cn/result/2026-09-06/5c45fac4-3352-4fd9-9b3d-ffb4f229e25b/6fe2a56b699e16844fa87ff7cee0f9f5d705fb712b4799cd6eaae5e0cb6c50af.png)  
图1文件系统配置验证工具输入输出示意图

FAT\_Gen\_Verify工具包括输入参数校验功能、XML文件的读取解析与校验功能、FS可加载文件的读取解析与校验功能、配置数据的符合性校验功能、FAT配置验证报告的生成功能和运行状态记录文件的生成功能。输入参数校验功能对用户输入的命令行参数进行合法性检查；XML文件读取解析与校验功能对文件系统配置文件进行读取与解析，并进行校验。FS可加载文件的读取解析与校验功能能对FS可加载文件进行读取与解析，并进行CRC校验。配置数据的符合性校验功能验证FS可加载文件的正确性，检查从待验证的FS可加载文件中读取的配置数据和根据转换关系计算得到的基准值的一致性；FAT配置验证报告的生成功能汇总配置数据的符合性校验结果并生成结构化的FAT配置验证报告；运行状态记录文件的生成功能记录工具运行过程中的关键状态与执行信息并生成运行状态记录文件。

FAT\_Gen\_Verify工具的输入为：

a)文件系统配置文件<XML>，可通过手工编辑获得，也可由其它工具生成，格式详见《文件系统配置生成工具接口控制文档》（TP-F4220TRD012）第五章节输入文件描述；

b)FS可加载文件<BIN>，由文件配置生成工具生成，格式详见《文件系统二进制格式定义文档》（F4220TICD002）和《文件系统配置生成工具和验证工具数据词典》（F4220TRTM028）第四章节数据词典描述，由FAT\_Gen配置生成工具生成。

FAT\_Gen\_Verify工具的输出为：

a)文件系统配置验证报告<CSV>；

b)运行状态记录文件<LOG>。

# 3 工具需求

FAT\_Gen\_Verify工具的需求规范定义过程参见《文件系统配置生成和验证工具开发计划》（F4220TDP003）。

FAT\_Gen\_Verify工具的需求规范的属性定义需符合《航电核心处理系统资源配置工具集工程管理计划》（F4210EMP001）第8.3章节要求。

FAT\_Gen\_Verify工具的需求规范需符合《文件系统配置验证工具操作需求规范》（F4220TORS038）要求。

XML定义参考《Extensible Markup Language (XML) 1.0 (Fifth Edition)》。

对于下文中括号的说明：

a) 大括号 { }

打印信息中的大括号{ }，其意为取{ }所包含的变量的值。打印内容并不包含{ }本身。例如 {YYYY}打印结果为2025，而不是{2025}。

b) 中括号[ ]

打印信息中的中括号[ ]，其意为固定信息分段显示。中括号[ ]及其包含的内容要按照原样打印。例如[ERROR]打印结果为[ERROR]

c) 小括号（ ）

打印信息中的小括号（），其意为提示或解释信息，是帮助理解的注释内容，不会被打印。例如[{文件名(含后缀)}]的打印结果为[test.xml]

d) 尖括号< >

打印信息中的尖括号< >，其意为命令行参数的占位符，表示需要用户输入的实际参数值。尖括号< >本身不会被打印，而是替换为用户输入的具体内容。例如<input\_xml\_file>的打印结果为/user/data.xml，而非</user/data.xml>。

e) 单引号' '

打印信息中的单引号' '，其意为对内部信息的强调。单引号' '及其包含的内容要按照原样打印。例如'{文件名(含后缀)}'的打印结果为'test.xml'。

对下文中时间戳的说明：

a) YYYY表示年份的四位数字，例如2025（2025年）

b) MM表示月份的两位数字，例如09（9月）

c) DD表示日期的两位数字，例如01（1日）

d) HH表示24小时制的小时数，例如16（16点）

e) mm表示两位的分钟数，例如59（59分）

f) ss表示两位的秒钟数，例如30（30秒）

打印信息中的时间戳，表示工具输出对应信息时的系统时间。

### 3.3.1 工具界面信息

FAT\_Gen\_Verify工具是Windows命令行模式运行的工具，FAT\_Gen\_Verify工具运行界面为CMD命令行窗口。

在所有需求中，FAT\_Gen\_Verify工具输出指定信息是指将指定内容打印至CMD命令行窗口。

FAT\_Gen\_Verify工具应能给用户提供命令行形式的输入接口，包括辅助功能命令（命令行格式详见第5.4.1章节-005188需求）和配置验证命令（命令行格式详见第5.4.1章节-005120需求）。

当从命令行接收到辅助功能命令时，FAT\_Gen\_Verify工具在运行过程中打印辅助信息，格式如下：

{Message}。

其中，

{Message}，是具体的辅助信息。

FAT\_Gen\_Verify工具在运行过程中打印描述（Info）信息，格式如下：[FAT\_Gen\_Verify][{YYYY-MM-DD HH:mm:ss}][Info] {Message}。

其中，

{YYYY-MM-DD HH:mm:ss}，是FAT\_Gen\_Verify工具打印描述（Info）信息的时间；

{Message}，是具体的描述信息。

FAT\_Gen\_Verify工具在运行过程中打印告警（Warning）信息，格式如下：[FAT\_Gen\_Verify][{YYYY-MM-DD HH:mm:ss}][Warning][{Code}] {Message}。

其中，

{YYYY-MM-DD HH:mm:ss}，是FAT\_Gen\_Verify工具打印告警（Warning）信息的时间；

{Code}为故障代码，具体详见表1；

{Message}，是具体的告警信息。

FAT\_Gen\_Verify工具在运行过程中打印错误（Error）信息，格式如下：

[FAT\_Gen\_Verify][{YYYY-MM-DD HH:mm:ss}][Error][{Code}] {Message}。

其中，

{YYYY-MM-DD HH:mm:ss}，是FAT\_Gen\_Verify工具打印错误（Error）信息的时间；

{Code}为故障代码，具体详见表1；

{Message}，是具体的错误信息。
