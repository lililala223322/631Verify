# 1 介绍

<a id="_Toc27833"></a>
## 1.1 目的

本文件由中国航空工业集团有限公司西安航空计算技术研究所（以下简称航空工业计算所）编制，旨在提供对以独立二进制配置数据形式存在的天脉操作系统ARINC653配置文件的说明，用于天脉操作系统和配置生成工具之间的接口定义。

<a id="_Toc2353"></a>
## 1.2 范围

本文件引用182-ACPS-0323-OSICD《操作系统ARINC653配置生成工具接口控制文档》，《操作系统ARINC653配置生成工具接口控制文档》中所包含的配置数据定义，将作为本文档的组成部分。同时，本文档补充了《操作系统ARINC653配置生成工具接口控制文档》所没有定义的内容，这些补充的内容包括：

1. Core OS、SharedLibraryRegion、HMTask配置元素的定义；
2. 《操作系统ARINC653配置生成工具接口控制文档》中未描述的可选属性的默认值定义；
3. Schedules、HealthMonitor元素中增加的可选子元素的定义。

本文件适用于操作系统软件和配置生成工具的开发方。
